# Spec Kit workflow

This repository uses Spec Kit-compatible artifacts. The current feature folder is `specs/001-playable-movement/`; project-wide rules are in `.specify/memory/constitution.md`.

## Workflow

For each bounded feature, use the installed Codex Spec Kit skills in order:

1. `$speckit-specify` — define user stories, requirements, and acceptance criteria.
2. `$speckit-clarify` — resolve meaningful open questions.
3. `$speckit-plan` — choose the technical approach.
4. `$speckit-tasks` — create ordered implementation tasks.
5. `$speckit-analyze` — check consistency between artifacts.
6. `$speckit-implement` — implement the feature.
7. `$speckit-converge` — verify the implementation against the spec.

For the official Codex integration and setup instructions, see https://github.github.io/spec-kit/integrations/codex.html and https://github.github.io/spec-kit/guides/existing-projects.html.
