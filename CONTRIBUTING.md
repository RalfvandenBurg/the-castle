# Contributing

## Workflow
1. Start from the current `main` branch and keep changes focused.
2. Read `AGENTS.md` and the relevant documents in `docs/` first.
3. Prefer a small playable change over adding a framework before it is needed.
4. Update documentation and `CHANGELOG.md` when player-facing behavior changes.
5. Run the Godot headless startup check for gameplay changes and describe any manual checks still needed.

## Content and assets
- Use original or properly licensed assets only.
- Keep source files in the repository; keep imports, caches, and export output out of commits.
- Do not recreate exact original room layouts from reference material. Use references to understand broad mechanics and make new room designs.

## Commit messages
Use short, action-oriented messages, for example `Add checkpoint-based respawn`.
